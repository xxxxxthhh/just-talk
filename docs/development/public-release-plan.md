# Just Talk 公开试用版与开源计划（修订版）

> 范围：让陌生人打开一个稳定的 HTTPS 地址即可免配置试用真实的发音评分与示范语音，同时开源代码。部署目标、隧道凭据、DNS 与公网切换由维护者在私有环境完成，本文不记录任何主机名、IP 或私有资源细节。

## 1. 目标与非目标

**目标**
- 真实可用：服务端持有 Azure 凭据，访客录音得到真实 Azure 发音评分与 TTS；不用 mock 分数冒充。
- 应用记录的调用用量有界：每访客日限额 + 全站日/月总量上限，持久化、跨重启、删数据/清 cookie 不重置。
- 数据隔离与可删除：每访客独立数据文件，可一键删除，闲置 7 天自动清理。
- 开源：MIT，自部署路径（个人模式 / 公开模式）文档化。
- 保护既有 iOS/Capacitor 能力：个人模式与 iOS 构建行为不变。

**非目标（本轮）**
- 账号体系、支付、多租户后台、App Store 发布、LLM 功能公开开放、非英语评分。

## 2. 关键决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 凭据模式 | 服务端托管 Azure key，非 BYOK | 访客免配置；成本靠应用内硬上限约束 |
| 访客身份 | 服务端签发 256-bit 随机令牌，HttpOnly+SameSite=Lax cookie，只存 SHA-256 | 无注册；cookie 不是反滥用手段，仅用于数据归属与公平分配 |
| 数据隔离 | 每访客一个 SQLite 文件，文件名只取服务端 id | 隔离由结构保证，删除即删文件；不改 1400 行存储层查询 |
| 计费口径 | 解码为 16 kHz WAV 后按实际帧数计秒；TTS 按字符（非 ASCII 记 2） | 不信任上传容器元数据 |
| 额度语义 | attempt 持久化预留；发送给 Azure 后永不返还、不自动重试；仅确定未发送才释放 | 失败/超时调用可能已计费 |
| 窗口 | UTC 自然日/月；写锁内单次采样窗口 | 跨日/月边界检查与记账一致 |
| 反滥用 | 全站总量 + attempt 次数上限为资金保障；访客签发全站每小时上限 + 活跃访客上限；每地址内存软节流；Turnstile 可选 | IP 不是身份；限制应用记录的调用用量，不能保证服务可用性或供应商账单封顶 |
| 部署形态 | 单应用多阶段镜像（前端公开构建 + FastAPI 同源服务），独立 compose，无宿主端口，Cloudflare Tunnel（配置与凭据只读挂载） | 独立容器和数据目录；无宿主机入站端口，同机资源与内核仍共享 |
| 前端开关 | 构建期 `VITE_PUBLIC_MODE=1` | 个人/iOS 构建零变化 |
| LLM | 公开模式强制关闭 | 先保证录音评分/词库主流程 |
| 名称/License | Just Talk / MIT | 与维护者其它开源项目一致 |

## 3. 默认上限（均可 env 配置）

| 范围 | 录音秒数 | TTS 字符 | 评分次数 | TTS 次数 |
| --- | --- | --- | --- | --- |
| 全站/月 | 14,400（4 h） | 100,000 | 1,500 | 3,000 |
| 全站/日 | 1,800（30 min） | 5,000 | 120 | 200 |
| 访客/日 | 180（3 min） | 1,000 | 20 | 40 |

另：短录音 30 s、长篇 90 s；上传 5 MB（流式截断，含 chunked）；JSON 256 KB；TTS 单次 600 字符；参考文本 1,500 字符；Azure 并发 2（有界等待 10 s）；活跃访客 300；新访客 30/小时；TTL 7 天；词库 500 词；导入 200 课 / 200,000 字符；字段长度上限（词 80、备注 1,000、课文 10,000、标题 200、标签 10×40）。

参考成本（估算，不是账单封顶）：按 Azure Retail Prices API（eastus，2026-09-24）评分 $1.00/h + prosody 附加（推断为 “Enhanced Feature Audio” $0.30/h）、Neural TTS $15/1M 字符，默认月上限约 4 × $1.30 + $1.50 ≈ $6.7/月；不含同一 key 的其它用量。

## 5. 已知风险与限制

- 匿名 cookie 可随时重置：访客限额只是公平分配；全站上限限制应用记录的调用用量，但恶意客户端可耗尽当日共享额度（可用性风险）。
- 额度按应用自身口径计量，不等于供应商账单；同一 Azure key 的其它用量不在内；Azure 预算只告警不止损。
- prosody 附加费的计费项名称为推断；计费粒度/最低计费以微软为准。
- 容器资源限制与只读根文件系统降低影响面，但不是强隔离；与其它服务同机仍有残余风险。宿主机防火墙（阻断内网/metadata）需部署时配置。
- 单进程部署假设：按访客写锁与 Azure 并发信号量在进程内。
- 内置素材、音素指南与图标的来源未独立核实，见 `docs/CONTENT-PROVENANCE.md`。
- 真实设备（iOS Safari / Android Chrome）录音兼容未在本轮测过；本轮只有维护者在桌面浏览器做了公开页面与真实 TTS 回读，移动视口布局尚待回读。
